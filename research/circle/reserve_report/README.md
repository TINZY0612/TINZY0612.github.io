# Published reserve-income report

`Circle_Reserve_Income_Report.docx` is the authoritative editable report. `Circle_Reserve_Income_Report.pdf` is the matching, visually checked 14-page export. `Circle_Reserve_Income_Report.md` and `site/circle/report.html` are generated from that same Word file, including its signed-error chart.

The chart uses the fund-yield method with the prior yield ratio at the late information cutoff. The financial calculations and the other nine tables are preserved.

For the project explanation, scope, data map and reproduction steps, start with the [project README](../README.md). Public source ledgers and tests are included; earlier local editing backups and licensed exports are not.

The small `repository/circle/` subtree supplies data/modules at the paths expected by the existing tests; it is not a nested Git repository. The actual public website lives at https://ziyik0612.me/circle/.
